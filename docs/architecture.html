Architecture Overview

Factory Inventory Management System

A full-stack demo for a Claude Code workshop. A Vue 3 single-page app reads inventory, order, demand, spending and report data from a FastAPI service. The service keeps all data in memory, loaded from JSON files.

System architecture

Two processes on one machine. The browser calls the API over HTTP. The API reads Python lists that mock_data.py loads one time at start. There is no database. The only write path is POST /api/restock-orders, which appends to an in-memory list.

Data flow: a filter change

The four global filters (time period, warehouse, category, order status) are the main path through all tiers. The value 'all' means "no filter" in every tier.

Client

User selects a filter

FilterBar.vue writes a module-level ref in useFilters.

Client

Views react

Each view has a watch on the refs it needs and calls its load function.

Client

Map parameter names

getCurrentFilters() maps location to warehouse and period to month.

Client

Build the request

api.js builds a query string without 'all' values and sends a GET.

API

Filter in memory

apply_filters() matches warehouse, category, status. filter_by_month() matches YYYY-MM or Q1-2025.

Data

Read the lists

The helpers read the lists from mock_data.py. No file I/O happens per request.

API

Calculate and validate

The dashboard route calculates KPIs. response_model validates list and detail responses.

Client

Render

Raw data goes into refs. computed properties build the charts and tables.

Known gaps

These items were confirmed in the code on 2026-11-05.

Tasks API missing

App.vue calls /api/tasks on mount. The backend has no such route, so the call returns 404.

Purchase order API missing

api.js defines calls to /api/purchase-orders. No route exists, and no component calls them yet.

Backlog view not routed

Backlog.vue exists, but main.js does not register it.

Stale data generator

generate_data.py writes orders.json with old categories that do not match the inventory.

Hardcoded values

The API URL is localhost:8001, and the quarter logic supports 2025 only.

Test drift

tests/README.md lists test_orders.py, which does not exist. The orders routes have no tests.

More detail is in the LLM Wiki: wiki/index.md. Source of truth: server/main.py, client/src/.
